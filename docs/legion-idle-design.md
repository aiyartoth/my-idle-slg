# 放置军团：设计方案（讨论稿）

状态：讨论中，未进入实现。  
建议默认已写进正文；文末「待确认」列出需要拍板的分叉。

## 1. 游戏是什么

玩家是军团主帅。上线时决定招什么兵、把哪位英雄配给哪支军团、派去哪条战线；下线后军团按编制自动作战、自动产出。回来读战报，改编制，再派出去。

策略来自**编制**，不来自操作。同一套兵力，前排用枪、后排用弓、主将带拒马，和前排用骑、后排用盾，打同一支敌人会是两种结果。

第一版目标：单机、浏览器、本地存档。一次上线约 3–8 分钟，离线至少 8 小时仍有可解释的收获与损失。

## 2. 设计支柱

1. **编制即策略。** 兵种克制、站位、英雄兵种亲和，三者叠在一起决定胜负。裸战力只能缩短差距，不能抹平克制。
2. **培养要取舍。** 英雄经验、技能材料和兵营队列都有限。养深一个主将，比六个英雄平均点一级更强。
3. **放置结果可解释。** 每份战报写清损失原因（被骑兵切后排、粮草不足士气下降、亲和不匹配）。玩家改的是编制，不是刷新到赢。
4. **扩张有维持成本。** 军团越多，粮草维护越高。铺满编制而养不起，会在离线时吃掉收益。

## 3. 核心循环

```text
收战报与资源
    → 补员 / 治疗 / 继续训练
    → 调整英雄与兵种比例
    → 把军团派回战线
    → 离线按 tick 结算
    → 下次上线
```

短循环（每次上线）：处理一支军团的伤兵和一次编制调整。  
中循环（数小时到一天）：一支兵营队列练完、一个英雄技能升一级、一条战线推过一关。  
长循环（数天）：解锁新兵阶、第二支军团、新的英雄亲和路线。

## 4. 资源

| 资源 | 从哪来 | 花在哪 | 紧张点 |
| --- | --- | --- | --- |
| 粮草 | 驻守战线、推进关卡 | 征兵、军团每小时维护 | 军团越多越贵，离线也会扣 |
| 金币 | 战斗、任务 | 英雄技能、兵营升级 | 与征兵抢优先级 |
| 预备兵 | 兵营队列按时产出 | 编入军团才变成上阵兵力 | 队列同时只能跑一种兵 |
| 军功 | 战斗结算 | 英雄等级 | 只有出战的英雄在涨 |
| 技能残页 | 精英关、战报额外掉落 | 技能升级 | 远少于可点的技能槽 |

伤兵不删除编制：进医馆，消耗时间与少量粮草归队。预备兵、上阵兵、伤兵是三种库存，撤编时未受伤的兵回到预备营。

粮草在离线时照样结算。余额不够支付维护时，不立刻解散军团，改为**士气逐 tick 下降**，战报里单独写出这一条。

## 5. 兵种招募

第一版四种兵。语言接近古典方阵，名字用职能，不绑具体历史人物。

| 兵种 | 职责 | 克制倾向 | 训练特点 |
| --- | --- | --- | --- |
| 盾兵 | 前排承伤 | 略克骑兵的冲锋 | 便宜、慢输出 |
| 枪兵 | 前排反骑 | 克骑兵 | 中等成本 |
| 骑兵 | 突击后排 | 克弓兵 | 贵、维护高 |
| 弓兵 | 后排输出 | 克枪兵，对盾兵有额外伤害 | 脆，必须有人挡在前面 |

### 5.1 克制系数（第一版）

攻击方对被攻击方的伤害倍率：

| 攻击 \ 防守 | 盾 | 枪 | 骑 | 弓 |
| --- | --- | --- | --- | --- |
| 盾 | 1.00 | 0.90 | 1.15 | 0.85 |
| 枪 | 0.95 | 1.00 | 1.35 | 0.80 |
| 骑 | 0.90 | 0.75 | 1.00 | 1.35 |
| 弓 | 1.20 | 1.35 | 0.80 | 1.00 |

系数是讨论用起点，实现前用一小组关卡回放校准。目标手感：正确克制能打过高自己约 15% 战力的敌人；克制拿反时，同战力也会亏。

### 5.2 招募怎么成为策略

兵营同一时间只有 **一条训练队列**。玩家选兵种、选阶级、选数量，然后等待。

- 兵营等级决定可训练的最高阶级。第一版开到 T3。
- T1 可花费时间与资源晋升，编制不用从零重招。
- 训练产出的是预备兵。只有拖进军团槽位才参战、才吃维护。
- 因此「兵营里有什么」和「军团里带什么」是两笔账。常见决策是：前线缺枪，但队列里正在赶弓——要不要拆队列。

第一版不做抽卡式兵种。新兵种靠兵营升级和战线章节解锁。

## 6. 英雄培养

英雄是指挥官，不是另一个兵种。他改变所在军团的打法，并只对**亲和兵种**给满额加成。

### 6.1 编制位置

- **主将**（1）：提供统率（决定这支军团的兵力上限）和开场战术。
- **副将**（1，第二支军团解锁前后开放）：提供一条光环或一个条件技能。

一个英雄同一时间只能待在一支军团里。

### 6.2 五条培养轴

| 轴 | 作用 | 消耗 | 取舍 |
| --- | --- | --- | --- |
| 等级 | 提高统率与技能基础值 | 军功（出战获得） | 坐冷板凳的英雄不涨 |
| 亲和 | 主兵种满加成，其余打折 | 英雄天生固定，不可洗 | 决定他该带哪支兵 |
| 技能 | 改变目标、开场规则、克制幅度 | 金币 + 技能残页 | 三个技能里优先点满一个 |
| 突破 | 提高等级上限、打开第 2/3 技能槽 | 同名印记（关卡与精英） | 印记绑在具体英雄上 |
| 装备 | 第一版不做 | — | 留给编制循环跑通之后 |

亲和规则：

- 主将亲和与该槽兵种一致：该兵伤害 ×1.15，受到伤害 ×0.90。
- 不一致：该兵伤害 ×0.90，受疗与减伤技能效果减半。
- 副将只给自己技能描述里写明的兵种加成，不重复吃主将亲和。

### 6.3 第一版英雄（6 人）

每人 1 个主亲和、1 个开场技能、1 个养成后技能。数字仍是起点。

| 英雄 | 亲和 | 开场技能 | 养成方向 |
| --- | --- | --- | --- |
| 墙垒 | 盾 | 坚守：盾兵承伤提高，输出略降 | 拖回合、保护后排 |
| 拒马 | 枪 | 扎营：前两回合骑兵对本军伤害降低 | 专门回答敌方骑兵 |
| 突骑 | 骑 | 冲锋：骑兵首击大幅提高，并优先打后排 | 切弓、怕枪墙 |
| 齐射 | 弓 | 两段射：弓兵同时打前排与后排各一部分 | 拆盾、打枪阵 |
| 押运 | 盾 | 稳饷：所在军团维护粮草降低 | 驻守与长离线 |
| 校尉 | 枪 | 整编：伤兵转化比例提高 | 推进关时减少永久损失 |

获取方式：主线战线到达指定关卡赠送。第一版没有招募池。玩家缺的是培养材料，不是图鉴。

## 7. 军团：策略真正落点

一支军团是玩家放置出去的最小单位。

```text
军团
├── 主将
├── 副将（可空）
├── 前排兵种 + 人数
├── 后排兵种 + 人数
├── 士气
└── 当前派遣（驻守 / 推进 / 修整）
```

规则：

- 前排 + 后排人数 ≤ 主将统率。
- 前排承担约 70% 的来袭伤害，直到前排兵力低于 30%。此后后排暴露，近战打后排伤害提高。
- 弓兵在前排时攻击正常，但承伤提高（站位错误要能在战报里看出来）。
- 骑兵在后排时失去「优先切敌后排」，冲锋技能按描述降档。
- 每小时维护 = 各兵种人数 × 该兵维护单价 × 士气系数。

玩家最初 1 支军团。主城或军功达到阈值后开放第 2 支，上到 3 支为止。第 2 支军团是第一版的主要扩张节点：收益变高，粮草压力同时出现。

### 7.1 推荐教学编制

用来验证克制是否读得懂，也是新手关的标准答案。

| 面对 | 建议编制 | 原因 |
| --- | --- | --- |
| 骑兵为主 | 前排枪 + 后排盾，主将拒马 | 枪克骑；盾减少被冲穿后弓兵不在场 |
| 枪兵为主 | 前排盾 + 后排弓，主将齐射 | 弓克枪；盾挡住枪的对前排输出 |
| 弓兵为主 | 前排盾 + 后排骑，主将突骑 | 骑切后排弓；盾先吃一轮齐射 |
| 长离线挂机 | 前排盾 + 后排枪，主将押运 | 维护低、编制稳，不追求最快推关 |

## 8. 战线与放置

军团同时只能处于一种派遣。

| 派遣 | 玩家得到什么 | 风险 |
| --- | --- | --- |
| 推进 | 推关卡、军功、技能残页、印记 | 伤兵、可能卡关 |
| 驻守 | 稳定粮草与金币，偶尔遭遇战 | 遭遇战若编制克制反了会掉士气 |
| 修整 | 士气恢复、医馆加速、维护减半 | 这期间没有战斗收益 |

推进是一串关卡，每关有固定敌方编制（对玩家可见：兵种比例 + 敌将技能名）。通关后该关变为可重复的低收益扫荡，高收益让给下一关。这样离线永远有事做，也不会无限刷同一关的稀有材料。

驻守点展示「常见来敌」的兵种倾向，方便玩家换上克制编制再挂机。

## 9. 离线结算

时间按 **60 秒一个 tick** 回放，上线时一次性算完。单次离线最多结算 **8 小时**，超出部分只给修整（士气缓慢回升，不再战斗）。

每个 tick 按派遣做一件事：

1. 扣维护，更新粮草与士气。
2. 推进：若士气高于阈值且兵力可战，打当前关的一场小战斗；否则停在关前，战报写明停因。
3. 驻守：发资源；每数个 tick 触发一场遭遇。
4. 修整：治疗一批伤兵，恢复一点士气。
5. 兵营队列独立计时，与军团是否出战无关。

战斗用同一套公式即时算出结果，不保存逐帧。战报保留：双方编制、克制带来的主要伤害份额、技能是否触发、士气修正、伤兵与阵亡、资源变化。阵亡比例低，大部分损失是伤兵，避免一次挂机直接清空养成。

上线第一屏只给三行结论，例如：

- 第二军团停在 3-4，前排枪兵被弓兵打残。
- 粮草在第 5 小时耗尽，士气掉到 40，之后战斗暂停。
- 兵营完成 T2 弓兵 120，尚在预备营。

点开才看完整战报。

## 10. 一场战斗怎么算

目的是让「换前排」在结果里看得见。流程固定，双方都不做即时操作。

1. 读双方前排 / 后排、人数、兵阶、士气、英雄技能。
2. 开场技能先结算（拒马、冲锋、齐射这一类）。
3. 若干回合：前排优先互相攻击；骑兵若技能允许则改打后排；弓兵按技能打前、后或两边。
4. 每一下伤害：

```text
伤害 = 攻击 × 兵阶系数 × 克制系数 × 亲和系数 × 技能系数 × 士气系数
       ÷ 防御系数
```

5. 前排人数跌破 30% 后，近战对后排的伤害提高。
6. 一方总兵力低于开战人数的 20%，或回合上限到达，结束。胜方按剩余兵力比例拿奖励，败方拿更少军功，双方都产生伤兵。

最小可预览的结算另写在 [战斗系统最小化预览](battle-min-preview.md)。预览里把「前排分摊约 70% 伤害」收成点名攻击：同一对兵种只对调前后排时，分摊模型的总输出不变，胜负翻不过来。点名攻击是否回写本节，等这场预览的结论。

士气低于 50 时，伤害与承伤同时变差，并禁止开启新的推进战斗。修整或打一场轻松驻守战可恢复。

## 11. 玩家一次上线的操作

按这个顺序设计界面，避免把放置游戏做成第二个经营清单。

1. **战报条。** 三行结论 + 可展开详情。
2. **军团卡。** 每张卡只显示：主将、前后排兵种人数、士气、派遣、伤兵。一个主按钮：「调整」或「继续」。
3. **调整面板。** 换将、换兵、从预备营补员。面板上实时显示对当前关卡敌人的克制提示（「弓兵面对敌方枪兵占优」），不自动帮玩家换上。
4. **兵营。** 一条队列：正在练什么、还要多久、完成后进预备营。
5. **英雄。** 从军团卡进入。只展示等级、三个技能、亲和。材料不够时按钮说明缺什么。

没有独立的「每日 20 个任务」作为核心。每日只保留一个可选的精英战：固定敌编制，掉技能残页，失败不掉养成。主循环在离线时已经转完。

## 12. 成长节奏（第一版）

| 阶段 | 玩家拥有 | 新出现的决策 |
| --- | --- | --- |
| 前 10 分钟 | 1 军团、盾 + 枪、英雄墙垒 | 看懂前排承伤 |
| 第 1 小时 | 弓兵、英雄齐射 | 第一次为克制换后排 |
| 第 1 天 | 骑兵、拒马与突骑、T2 | 队列只能练一种兵；维护开始咬人 |
| 第 2–3 天 | 第 2 军团、副将、押运或校尉 | 一支推进、一支驻守；粮草分配 |
| 之后 | T3、技能槽点满的取舍 | 印记给谁突破 |

数值上让第 2 军团在第 1 天结束时「看得到、养不起」，第 2 天粮草建筑或驻守收益上来之后才养得动。这个落差是第一版想验证的乐趣。

## 13. 第一版范围

做：

- 本地存档的单机循环（离线 tick、战报、补员、训练、换编制、推关、驻守、修整）
- 4 兵种、T1–T3、6 英雄、最多 3 军团（内容按上表逐步放开，存档结构先按 3 军团设计）
- 克制、站位、亲和、士气、维护，全部进同一条伤害公式
- 一章约 15 关的推进 + 2 个驻守点 + 若干精英战

先不做：

- 账号、排行、异步 PvP
- 抽卡与招募池
- 装备、宠物、独立城建树
- 逐帧手操战斗
- 联盟与大地图占点

城建若出现，只保留三个入口：兵营（解锁兵阶与队列速度）、医馆（伤兵速度）、粮仓（粮草上限与少量产量）。它们服务于征兵和维持，不单独做一条模拟经营线。

## 14. 存档需要记住的状态

实现时围绕这些数据，避免把界面状态写进规则。

```text
Player
  food, gold, merit, skillPages
  barracksLevel, hospitalLevel, granaryLevel
  trainQueue: { unitId, tier, count, finishAt } | null
  reserves: UnitStack[]          // 预备兵
  wounded: UnitStack[]           // 伤兵
  heroes: HeroState[]            // 等级、突破、技能等级、所属军团
  legions: Legion[]              // 将领、前后排、士气、派遣、当前关卡
  campaign: { chapter, clearedStageIds }
  lastTickAt                       // 上次结算时间
```

`lastTickAt` 是放置正确性的关键。结算必须可重入：同一时间段重复计算得到同一份战报，避免刷新页面双倍发奖。

## 15. 怎么判断设计成立

第一版做完后用这四条验收，不看功能清单是否铺满。

1. 新手不看数值，只换前排兵种，能打过原先打不过的关。
2. 把亲和英雄换成错兵种英雄，战报里能指出伤害下降。
3. 挂机超过粮草承受时长后，军团停战并写明原因，而不是默默亏光兵力。
4. 只开第 2 军团、不增加粮草时，两支军团的净收益低于单军团推进。

## 16. 待确认

下列项正文里已按建议默认往下写。改其中一条，会连带改英雄表或第一版范围。

| 项 | 建议默认 | 若改走另一边 |
| --- | --- | --- |
| 平台 | 浏览器单机，本地存档 | 移动端优先则界面按竖屏重排，规则可不变 |
| 题材 | 架空边军，职能兵种名 | 若定三国 / 魔幻，替换英雄与兵种名字，克制表可保留 |
| 战斗表现 | 战报 + 简短回合摘要 | 若要可视会战，仍用同一结算，只加演出 |
| 英雄获取 | 关卡赠送，无招募池 | 若要招募池，培养材料投放要改，避免「缺英雄」盖过「缺编制」 |
| 军团规模 | 最多 3 支，每支前/后两排 | 若要侧翼第三槽，克制会更深，第一版教学要加一关 |
| 离线上限 | 8 小时 | 若要 24 小时，驻守收益和粮草消耗要一起放大，否则会鼓励纯挂机 |

下一轮讨论建议先定：题材、要不要招募池、军团是两排还是三排。这三项定了就可以拆实现任务。
